Ethan Bayer's Site Plan

Site name: Hobby and Goal Tracker

I chose this name because this site will let you track a few different hobbies and set goals.

Site Purpose:

This site will allow someone to track some info related to reading and speedrunning hobbies, as well as make a goal planning sheet. The info related to the hobbies will be dynamically displayed using javascript.

Scenarios:

  • Which book on my to be read list has the most words?
  • Which of my speedrunning personal bests is the oldest?

Color Scheme:

  • Heading and footer background color/dark text: Carbon Black | Hex: #252422
  • Hobby card header/accent color: Tangerine Dream | Hex: #F49D7B
  • Accent Color Charcoal Brown | Hex: #403D39
  • Menu Text color: Dust Grey | Hex: #CCC5B9
  • General page background color and light text color: Floral White | Hex: #fcfaf2

Typography:

I will use the Montserrat font for everything, I'm not yet sure which weights I will use and where.
